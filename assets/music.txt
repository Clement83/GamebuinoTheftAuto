# Bande son du demake -- une piste par ambiance de quartier, 2 voix (basse + melodie).
# Le sequenceur (gta/mod_music.h) lit poiAtTile() et bascule de piste selon le POI
# ou se trouve le joueur (le meme nom qui s'affiche en bas a gauche). Compos
# *originales* facon GTA -> aucun souci de droits.
#
# Genere gta/music_data.cpp via : .venv/bin/python -m tools.build_music
#
# Format :
#   TRACK: nom        -> debute une piste (le bloc TEMPO/BASS/LEAD qui suit la decrit).
#   TEMPO: N          -> N frames par pas (1 pas = double-croche). 25 fps -> 1 frame = 40 ms.
#   BASS: ...         -> voix grave. LEAD: ... -> voix aigue. Lignes multiples concatenees.
#   ZONE: piste = PoiA, PoiB, ...  -> quels quartiers (noms de POI exacts) jouent cette piste.
#   DEFAULT: piste    -> piste de depart / repli.
# Tokens de note : C4 A2 D#3 (notation anglaise) ; . = re-pluck (meme note) ; - = silence.
# Un POI non liste garde la musique courante (pas de coupure sur les routes / petits services).
