# GTA Gamebuino Demake — Plan M3 : Viewer interactif PC

> **For agentic workers:** Implémenté via superpowers:subagent-driven-development (TDD par tâche, review spec puis qualité). Cases `- [ ]` pour le suivi.

**Goal:** Un viewer pygame où l'on conduit le perso dans la ville compilée (collisions réelles, glissement le long des murs, scroll fluide, zoom réglable) avec un overlay matérialisant le cadre 80×64 que la Gamebuino afficherait. Le comportement (caméra, collision) vit dans un moteur **pur** (`tools/engine.py`) testé headless.

**Architecture:**
- `tools/engine.py` — fonctions pures, **aucun import pygame**, source de vérité du comportement (parallèle au futur `engine.h` C++ ; parité reportée à M4). Paramètres explicites.
- `tools/viewer.py` — viewer pygame. **Recompile `city/city.txt` en mémoire** (`build_city.load_tiles` + `citydsl.compile_city`) pour obtenir `CompiledCity` + `solid_set` — pas de parsing du C++. Charge `assets/tiles8/*.png` et `assets/sprites8/player_*.png`.
- `tools/build_assets.py` — modif M1 ciblée : émet aussi `assets/sprites8/player_<dir>_<frame>.png` (source unique de la dérivation directionnelle).

**Convention d'exécution :** depuis la racine du dépôt. Modules via `python3 -m tools.<module>`. **pytest = `.venv/bin/python -m pytest`** (pas le python système). Le viewer interactif (`python3 -m tools.viewer`) se lance avec `.venv/bin/python`.

**Contrat partagé :** `TILE=8`, `PLAYER=8`. Écran Gamebuino = **80×64**. Position perso en **pixels monde**. Directions `north=0, east=1, south=2, west=3`. `cityMap[ty*w+tx]` row-major. Tuiles solides via `solid_set` (issu de `tileset.csv` colonne `solid=1` → `{5,6,7}` = water, building_a, building_b).

**Hors-scope (YAGNI) :** parité `engine.h` C++ (M4), mode démo auto-walk (M4), voitures/PNJ/audio, `preview.gif`.

## Task 1 : `tools/engine.py` — moteur pur + tests (TDD)

**Files:** Create `tools/engine.py`, `tools/tests/test_engine.py`.

API (pure, paramètres explicites) :
- `clamp_camera(player_px, world_px, screen_px) -> int` : retourne `max(0, min(player_px, world_px - screen_px))` si `world_px > screen_px`, sinon `0`. (`player_px` = coin caméra désiré déjà = `centre_perso - écran/2`, calculé par l'appelant ; cette fonction ne fait que **clamper**.)
- `is_solid(grid, w, h, solid_set, tx, ty) -> bool` : hors-bornes (`tx<0 or tx>=w or ty<0 or ty>=h`) → `True` ; sinon `grid[ty*w+tx] in solid_set`.
- `try_move(x, y, dx, dy, grid, w, h, solid_set) -> (nx, ny)` : position pixels, AABB perso `PLAYER×PLAYER`. Collision **axe par axe** : tente `x+dx`, si l'AABB chevauche une tuile solide → garde l'ancien x ; idem pour `y+dy` (à partir du x résolu). Renvoie `(nx, ny)`. Glissement le long des murs émerge de la séparation des axes.

Constantes module : `TILE = 8`, `PLAYER = 8`.

Helper interne suggéré : `_box_hits_solid(px, py, grid, w, h, solid_set)` → teste les tuiles chevauchées par la boîte `[px, px+PLAYER-1] × [py, py+PLAYER-1]` (de `px//TILE` à `(px+PLAYER-1)//TILE`, idem y) via `is_solid`.

- [ ] **Step 1 : tests qui échouent** — `tools/tests/test_engine.py` :
```python
import pytest
from tools.engine import clamp_camera, is_solid, try_move, TILE, PLAYER

# Petite ville 5x5 (40x40 px). Mur vertical solide en colonne tx=2.
W, H = 5, 5
SOLID = {1}
def _grid():
    g = [0] * (W * H)
    for y in range(H):
        g[y * W + 2] = 1   # colonne 2 solide
    return g


def test_clamp_camera_bounds():
    world, screen = 40, 24
    assert clamp_camera(-5, world, screen) == 0          # jamais negatif
    assert clamp_camera(100, world, screen) == world - screen  # clampe a droite
    assert clamp_camera(10, world, screen) == 10         # interieur inchange
    # monde plus petit que l'ecran -> 0
    assert clamp_camera(10, 16, 24) == 0


def test_is_solid_oob_and_tiles():
    g = _grid()
    assert is_solid(g, W, H, SOLID, -1, 0) is True       # hors-bornes = solide
    assert is_solid(g, W, H, SOLID, 0, 10) is True
    assert is_solid(g, W, H, SOLID, 2, 0) is True        # tuile solide
    assert is_solid(g, W, H, SOLID, 0, 0) is False       # herbe


def test_try_move_blocks_into_solid():
    g = _grid()
    # perso 8x8 a (8,0) (tuile 1,0), tente d'aller a droite vers la colonne solide 2
    nx, ny = try_move(8, 0, 4, 0, g, W, H, SOLID)
    assert nx == 8 and ny == 0           # bloque (AABB toucherait tx=2)


def test_try_move_slides_along_wall():
    g = _grid()
    # contre le mur (x bloque) mais mouvement diagonal -> glisse en y
    nx, ny = try_move(8, 0, 4, 4, g, W, H, SOLID)
    assert nx == 8                        # x bloque par le mur
    assert ny == 4                        # y glisse


def test_try_move_stays_in_bounds():
    g = _grid()
    nx, ny = try_move(0, 0, -4, -4, g, W, H, SOLID)
    assert nx == 0 and ny == 0            # hors-bornes = solide -> bloque
```

## Task 4 : `tools/viewer.py` (pygame) + vérification

**Files:** Create `tools/viewer.py`.

`viewer.py` :
- **Chargement** : `tile_index, solid_set, names = build_city.load_tiles("assets/tileset.csv")` ; `text = open("city/city.txt").read()` ; `city = citydsl.compile_city(text, tile_index, solid_set)`. Charger `assets/tiles8/<name>.png` pour chaque nom, et `assets/sprites8/player_<dir>_<frame>.png` (dict indexé `[dir][frame]`, `convert_alpha()`).
- **État** : `px, py = city.spawn[0]*TILE, city.spawn[1]*TILE` ; `direction = city.spawn[2]` ; `frame = 0` ; `anim_timer`. Zoom `Z = 4`.
- **Boucle** : `pygame.time.Clock().tick(60)`. Events : `QUIT`/`Échap` → sortie ; `+`/`-` (et `=`/`KP_PLUS`/`KP_MINUS`) → ajuster `Z` (borne min = voir toute la ville, max ~16). Touches fléchées tenues (`pygame.key.get_pressed()`) → `(dx,dy)` (1px/frame ; si deux axes, autoriser le diagonal — `try_move` gère). Si déplacement : `px,py = try_move(px,py,dx,dy,city.grid,city.w,city.h,solid_set)`, mettre à jour `direction` (selon l'axe dominant du mouvement effectif), avancer `anim_timer` → alterner `frame` toutes ~8 frames ; sinon `frame=0`.
- **Caméra** (en pixels monde) : `cam_x = clamp_camera(px + PLAYER//2 - view_w//2, city.w*TILE, view_w)` où `view_w = WIN_W // Z` ; idem `cam_y`. (`WIN_W, WIN_H` = taille fenêtre fixe, ex. 800×640.)
- **Rendu** : pour chaque tuile visible `[cam_x//TILE .. ]`, blit `tiles8[name]` scalé à `TILE*Z` à `((tx*TILE - cam_x)*Z, (ty*TILE - cam_y)*Z)`. Blit le perso `sprites[direction][frame]` scalé à `PLAYER*Z` à sa position écran. **Overlay** : `dev_x = clamp_camera(px+PLAYER//2-40, city.w*TILE, 80)`, `dev_y = clamp_camera(py+PLAYER//2-32, city.h*TILE, 64)` → `pygame.draw.rect` (contour, ex. magenta/jaune) au rectangle `((dev_x-cam_x)*Z, (dev_y-cam_y)*Z, 80*Z, 64*Z)`.
- `if __name__ == "__main__": main()`.

> `viewer.py` n'est pas testé unitairement (il consomme `engine.py` testé). Pour détecter les crashes au chargement/au premier frame **sans écran**, l'implémenteur fait un smoke-test : `SDL_VIDEODRIVER=dummy .venv/bin/python -c "import tools.viewer as v; ..."` qui initialise, charge les assets et exécute **un** tour de rendu hors boucle (factoriser le rendu d'un frame dans une fonction appelable, ex. `render_frame(screen, state)`), puis quitte. Aucune dépendance à un display réel.
